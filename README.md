## ✨ Portfolio Features

- 🎨 **Modern Dark-Themed UI:** Sleek glassmorphism style with purple/cyan gradients and smooth animations.
- 📱 **Fully Responsive:** Auto-adapting layout across mobile, tablet, laptop, and desktop viewports.
- ⚡ **Interactive Animations:** Auto-hide/show navigation bar, smooth scrolling, animated hero section, and modern hover effects.
- 📄 **Resume Download:** Direct access to download the latest PDF resume (`Aneej_R_Suku_Resume.pdf`).
- 💼 **Project Showcase:** Live project cards complete with tech tags, descriptions, GitHub repos, and live demos.
- 🛠️ **Developer UI:** 3D-inspired visual elements, experience timeline, and mobile navigation menu.

## 🏗️ Production Build & Local Setup
Clone the repository:

Bash
git clone [https://github.com/aneejrs/YOUR-REPO-NAME.git](https://github.com/aneejrs/new-portfolio-dwployment.git)
cd portfolio
Install dependencies:

Bash
npm install
Run the development server:

Bash
npm run dev
Create and test a production build:

Bash
npm run build
npm start


 🚀 Deployment
