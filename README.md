## ✨ Portfolio Features

- 🎨 **Modern Dark-Themed UI:** Sleek glassmorphism style with smooth gradient accents.
- 📱 **Fully Responsive:** Optimized for desktop, laptop, tablet, and mobile displays.
- ⚡ **Interactive Grid Canvas:** Dynamic interactive background elements.
- 📄 **Resume Integration:** Direct one-click download access to `Aneej_R_Suku_Resume.pdf`.
- 💼 **Project Filtering:** Dynamic categorization of production applications, personal projects, and full-stack work.
- 🚀 **Fast Performance:** Server-Side Rendering (SSR) & static optimization powered by Next.js App Router.

---

## 📂 Website Sections

- 🏠 **Hero:** Introduction, quick bio, technology stack badges, social links, and call-to-actions.
- 👨‍💻 **About:** In-depth background overview detailing development experience and methodology.
- ⚡ **Skills:** Categorized technical expertise covering Frontend, State Management, Tools, and Databases.
- 🏆 **Certifications:** Key achievements and certifications, including Front End Development Internship (Wynxio Technologies), Developer Essentials (Kerala Blockchain Academy), and DevOps/Cloud computing workshops.
- 💼 **Experience:** Interactive timeline showcasing professional roles and responsibilities.
- 🚀 **Projects:** Live project cards complete with tech tags, descriptions, live demo links, and GitHub repositories.
- 📩 **Contact:** Instant contact capabilities via Email, LinkedIn, and GitHub.
